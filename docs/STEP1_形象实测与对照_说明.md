## 2. ★ 交接书里被证伪的两条推测（务必覆盖）

| # | 交接书原文推测 | 实测结论 |
|---|---|---|
| 1 | "白色月牙 + 高光点**绕圆心旋转**，122 帧构成一个闭环" | ❌ **完全不旋转。** 对 122 帧做极坐标展开后逐一做角度互相关，**相邻帧最佳角度偏移恒为 0°，相关系数 0.991**；相对首帧的最佳偏移也全是 0。角速度 **0.00°/s** |

## 4. ★ 透明通道行为（mp4 浅色背景帧给出的硬证据）

从 mp4 里取到一帧桌面为**浅色（近白 UI）**的画面：

1. **宠物外缘之外完全看不到发光** —— 紧邻边缘的像素与远处 UI 底色一致。
2. 浅底上宠物呈**一个蓝色实体盘 + 白环 + 白球**，边缘清晰。

→ 结论：**那份"大范围柔和外发光"是加性（additive/bloom）性质的，在浅色背景上不可见**，
不是"深色半透明光晕"。真正叠在浅色桌面上不会糊一圈灰蓝。

**实现取舍（已写进渲染器）**：Windows 分层窗口只能做 alpha 混合、做不了加性。
所以采用 **unpremultiply** 方案：
先构建"黑底下的最终观感"色彩场（与素材逐像素对齐），再按 `alpha = max(RGB)/255` 反解出真实颜色。
效果：**暗色桌面上与素材完全一致（逐像素），浅色桌面上只留一圈克制的淡蓝**（不是灰雾）。
参数 `GLOW_POWER` 可调（1.0 = 暗底逐像素一致；调大则浅底光晕更紧、暗底略暗）。

## 7. 已知剩余差异（不藏）

1. **外层蓝区少了素材上的多边形/花瓣状纹理**。浅浅量过：视频实拍里宠物外缘是**十二边形（scalloped dodecagon）**轮廓；在 GIF 里加这个模反而让 MAE 变差（7.0 → 8.9），说明 GIF 资产本身是**圆**（或纹理幅度极小）。**本版按 GIF 做圆，保留 `POLY_AMOUNT` 参数备用。**
2. **0.6–0.8R 略暗 3~6 个色阶**：素材那一圈有轻微的径向"光芒"纹理，我用中位数剖面所以偏暗，属可控偏差。
3. **素材图上的横向条纹是 GIF 抖动噪点**，不是形象的一部分，已刻意不复刻。
4. 内盘 0–0.1R 的 MAE 11.78 最大：小球与内盘过渡的柔和度还差一点，属可继续打磨项。
