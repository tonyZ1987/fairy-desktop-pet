# Fairy · Windows 桌面宠物

把「Fairy」做成一只真正的桌面挂件：**无边框、逐像素透明、始终置顶、60 fps**。

它会在你干活的时候**半睁着眼**——外圈那层辉光会"卸下伪装"，碎成 **0/1 的数字流**；
活干完了，它弹一张小卡片告诉你「XX 已完成，请前往查阅」。你不需要盯着任何窗口。

## 二、快速开始

### 环境要求

- **Windows 10 / 11**
- **Python 3.10+**（不需要 tkinter、不需要 Qt —— 只用 `ctypes` 直接调 Win32）

### 安装与运行

```bat
pip install -r requirements.txt
```

然后**双击 `start_fairy.vbs`**。

> ⏳ **首次启动会先烘焙缓存**：默认尺寸 260 px 约 **100 秒**（实测 99.6 s）。
> 这段时间窗口不会出现，属正常 —— 烘完自己就出来了。之后每次启动都是**秒开**（缓存载入 0.19 s）。
> 想一次把三档尺寸都烘好（约 5~6 分钟）：`python fairy_bake.py 200 260 320`

**推荐用 `restart_fairy.vbs`**：它先结束旧实例再起新的，保证跑的是最新代码。

### 找不到 Python 怎么办

启动器**不写死任何路径**，按以下顺序自动找：

1. 环境变量 `FAIRY_PYTHON`（指向 `pythonw.exe` 的完整路径）
2. **脚本同目录下的 `python_path.txt`**（里面放一行路径就行）
3. `PATH` 里的 `pythonw.exe`
4. 标准安装目录（`%LOCALAPPDATA%\Programs\Python`、`%ProgramFiles%\Python*`）

所以：**官方安装包 + 勾选 "Add python.exe to PATH" ⇒ 什么都不用配**。
如果你的 Python 在非标准位置（便携版、虚拟环境等），
在本目录放一个 `python_path.txt`，内容一行即可：

```
D:\Python311\pythonw.exe
```

（这个文件已在 `.gitignore` 里，不会跟着提交上去。）

### 万一没出现

双击 **`check_fairy.vbs`** —— 它会弹窗告诉你结论（进程在不在、窗口可见不可见、最近有没有报错）。

## 三、怎么用

### 3.1 右键菜单

![菜单](docs/images/STEP12_菜单_滑块式.png)

| 行 | 说明 |
|---|---|
| **尺寸** | 小 200 / 中 260 / 大 320 px（滑块可点可拖，缓存都是现成的，秒切） |
| **模式** | **自动**：跟随状态文件；**手动**：你自己指定常态/工作态 |
| **自动** | `跟随 WorkBuddy`（读 `state.json`）/ `60 秒循环`（演示用，自己来回切） |
| **状态** | 切到手动时出现，直接在常态 / 工作态之间选 |
| **置顶** | 开：始终在最上层；关：允许被其它窗口盖住（**重启后保持**） |
| **归位** | 回到右下角（找不到它时用这个） |
| **退出** | 退出 |

左键拖动可移动；双击它会说一句话。

### 3.2 状态是怎么来的 —— 两个纯文本文件

桌宠**只认文件**，不碰网络、不碰别的程序、不需要任何权限。你（或任何脚本）写文件，它照做。

**① `state.json` —— 眼睛的状态**

```json
{ "state": "working", "ts": "2026-09-22T10:00:00", "ttl": 2700, "note": "任务开始" }
```

- `state`：`working` → 半睁眼 + 辉光变 0/1；`idle` → 睁眼
  （也认 `thinking` / `busy` / `normal` 等同义词）
- `ttl`：**兜底秒数**。文件超过这么久没更新，自动回落到 `idle`，防止"忘了改回来"一直半睁
- 优先级：右键菜单手动指定 > `state.json` > 默认 `idle`

**② `notify.json` —— 任务完成通知**

```json
{ "text": "主人，报告写完了，请前往查阅。", "secs": 12 }
```

桌宠每 0.5 秒轮询一次，读到就弹卡片（自动折行、最多 3 行、带淡入淡出），**读完立即删除** ——
所以通知是一次性的，重启不会重弹。

命令行直接发：

```bat
python fairy_notify.py "报告写完了" --done
```

- `--done`：同时把 `state.json` 置为 `idle`（收工，睁眼）
- `--work`：置为 `working`（开工，半睁眼）
- `--test`：发一条测试通知

不想敲命令行？双击 **`test_notify.vbs`** 就能看到卡片效果。

### 3.3 不碰鼠标的开关

在这个目录里放一个文件就行：

| 文件 | 作用 |
|---|---|
| `stop.txt` | 桌宠自己退出（并删掉它）—— 适合写脚本 |
| `poke.txt` | 让它归位并亮出来（**再双击一次启动器也是这个效果**） |

## 五、技术要点（想改代码的话）

这个项目最花时间的不是"画一只猫"，而是**让它 60 fps 跑起来、且 15 秒无缝循环**。几条硬经验：

1. **别照抄帧率**：原素材 GIF 是 30/40 ms 交替（≈29 fps），直接播放就是"不顺滑"的根源。
   本项目走**连续参数化 + 60 fps**，不逐帧播放。
2. **图层预栅格化 + 相位表查表**：把"每帧算一遍"改成"预烘 180 个相位帧，运行时查表"，
   单帧从数百毫秒降到 **6~9 ms**。眼睛四层各预烘 90 相位；睫毛用解析式（旋转方形并集）。
3. **画布直接用 BGR 通道序存**：省掉每帧一次全幅通道翻转。
4. **绝对时间网格调度**：`next_t += interval` 而不是 `now - last >= interval`，
   否则每帧固定漂移、实测只有 56 fps；再配 `timeBeginPeriod(1)`，否则 sleep 粒度 15.6 ms、直接掉到 30 fps。
5. **准周期闭合**：要求"看起来无规律，但首尾帧必须无缝"时，让每个谐波在周期内转**整数圈**
   （`n_k = round(k/2)`）。**千万不要靠删谐波来凑闭合** —— 那会把形状变成 N 重对称，一眼就看出来。
6. **光晕不要"建模"，要"照素材量贴图"**：拿原素材量出径向剖面 + 角向图案，直接照抄。
   自己写公式捏出来的，通常就是一圈很假的实心环。
7. **不饱和铁律**：`峰值 × 最大叠加倍数 < 250`。
8. **`ImageChops.*` 返回新对象**：混在"复用的内部画布"上会造成**极隐蔽**的 bug ——
   测试查返回值永远正常，程序用内部画布就缺一大块。见 `fairy_layers.py:draw()` 末尾的注释。

## 六、已知限制

- **仅 Windows**。整窗口靠 `UpdateLayeredWindow` + `WS_EX_LAYERED`，没有跨平台抽象层。
- **形象是"重建"不是"导入"**：几何按官方 SVG 源码逐项复刻（见 `docs/STEP1B`），
  所以能 60 fps 实时渲染；代价是**与游戏内并非逐像素一致**。
- **光源是"贴图"不是"物理"**：外圈辉光是把原素材量下来照抄的，不是体积光模拟。
- **只显示在虚拟桌面的工作区内**，不会跑到任务栏底下。
- 通知卡片是**一次性**的：读完即删，不留历史。
- 界面文案里的称呼是写死的「主人」，想改成别的直接改 `fairy_pet.py` / `fairy_notify.py` 里的字符串。
