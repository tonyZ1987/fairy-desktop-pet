使用说明

一只待在桌面上的小挂件，只做一件事：让「我正在干活」一眼可见。

干活时，它半睁着眼，外圈辉光碎成一串 0/1 的数字流，下面挂一条进度条； 活干完了，它弹一张小卡片告诉你。你不需要盯着任何窗口 —— 抬头看一眼就够了。

工作态：半睁眼、外圈数字流、下方进度条

一、它什么时候会动

它自己不会凭空忙起来 —— 只有「有人告诉它」或「感知到你那边的 AI 在动」才会切状态。

情形它的表现
刚启动常态（睁眼、安静）—— 上一轮的工作态不会被继承
有任务开始半睁眼（工作态），此时通常还没有进度条
任务拆好步骤、开始推进半睁眼 + 进度条，按最小 1% 的台阶往上爬
任务跑完弹一张完成卡，进度条到 100% 后停一会儿再消失
你发的消息被接住了立刻半睁、先不出进度条，一直保持到它把话说完（中间不闪）
一句话：你一发消息它就半睁，一直到它把话说完。 任务还在跑的时候也不会「闪回」常态 —— 这是特意调过的。

二、怎么操作

  • 拖动：按住左键拖到任意位置，松手就停在那儿。
  • 双击：它会说一句话（不会弹窗、不抢焦点）。
  • 右键：打开菜单 —— 显示 / 行为 / 播放开机动画 / 归位 / 退出。
  • 找不到它了：右键菜单里点「归位（右下角）」，或者再双击一次启动器。

右键菜单分两级：主菜单只放导航和动作，设置都收在二级页里

菜单里悬停 5 秒会浮出一行说明；不需要记。

三、让它跟 AI 配合（推荐做一次）

它靠「别人告诉它」才知道你在干活。如果你电脑上跑着 WorkBuddy 这类 AI 工具， 可以让 AI 在每次接活时自动告诉它 —— 装一次，以后不用管。

  1. 在 Fairy 目录里双击 install_agent_bridge.vbs，弹出「装好了」即可。
  2. 开一个新的 AI 任务（已经在跑的老任务要新开一次才会读到）。
  3. 之后 AI 每接一个活，它就会自动半睁、报进度、干完弹卡。
不想用了：双击 uninstall_agent_bridge.vbs，配置会被摘干净。
中途想临时静音（不改配置）：在 Fairy 目录里新建一个空文件 fairy_bridge_off。

四、不装桥接也能用（会敲命令行的话）

四条命令就够：

python fairy_notify.py --work "接单：改通知卡圆角"     :: 切工作态（先不出进度条）
python fairy_notify.py --plan 3 "查现状/出候选/落地"   :: 拆好步骤 ⇒ 进度条登场
python fairy_notify.py --item 1 2                      :: 第 1 项的第 2 小段完成
python fairy_notify.py --reply "主人，3 项修改已完成。"   :: 跑到 100% + 弹完成卡

不想敲命令的话，双击 test_notify.vbs 就能看到卡片效果。

五、它怎么知道"你在干活"

你那边发生的事它的反应
任务被拆成 N 步进度条出现，从 0% 开始
某一步做完进度条往前走一格（不会突然跳）
你点「停止 / 取消」它立刻回常态，不占着进度条
同时开了好几个任务进度条只跟最先开始的那个；它完了条就消失（不接棒给下一个）
任务卡住不动了几分钟后它自己放手、回常态

安装指南

三步：装 Python → 解压 → 双击。之后每次开机只要双击一次（或让它自启）。

一、环境

项目要求
系统Windows 10 / 11（只有 Windows 版）
Python3.10 或更高，装的时候记得勾上 Add python.exe to PATH
其它依赖不需要额外装界面库（不需要 tkinter / Qt），pip install -r requirements.txt 即可
官方安装包 + 勾选 Add python.exe to PATH ⇒ 放哪儿都能跑，不用做任何配置。 中文路径也可以。

二、装

  1. 把整个文件夹解压到任意位置（建议路径别太深）。
  2. 双击 start_fairy.vbs —— 它会自己在屏幕右下角出现。
  3. 第一次会慢，见下节。

三、第一次启动会慢一次，之后秒开

阶段说明
① 倒计时小窗第一次需要预生成图像缓存，屏幕正中会出现一块倒计时窗（常见档位约 100 秒）。窗口不出来也是正常的，别急着关。
② 开机动画缓存好了播一遍开机动画 → 它在屏幕中央登场 → 自己走到右下角。
③ 以后每次缓存命中 ⇒ 约 0.2 秒秒开。

想一次性把三档都生成好（约 5~6 分钟，之后换档也是秒开）：

python fairy_bake.py 200 260 320

它启动时会自己测屏幕决定大小档位：小屏 200 / 全高清 260 / 2K 以上 320（只认主屏）， 也可以在右键菜单里手动改。

四、找不到 Python？

启动器不写死任何机器路径，会按顺序自己找：

环境变量 FAIRY_PYTHON  →  同目录的 python_path.txt  →  常见安装目录  →  系统 PATH

如果你用的是便携版 Python 或虚拟环境，就在目录里放一个 python_path.txt，写一行路径就行：

D:\Python311\pythonw.exe

五、怀疑没起来？

双击 check_fairy.vbs —— 它会弹窗直接告诉你结论（进程在不在、窗口可见不可见、最近有没有报错）。

文件什么时候用
start_fairy.vbs启动
restart_fairy.vbs改过设置/换过档位后重启（先关旧的再起新的）
check_fairy.vbs怀疑没起来、或者行为不对时的体检
install_agent_bridge.vbs让 AI 自动配合（可选，装一次）
uninstall_agent_bridge.vbs撤销上一条

六、卸载

  • 右键菜单 → 退出 Fairy；如果装过桥接，再双击 uninstall_agent_bridge.vbs。
  • 最后把整个文件夹删掉即可 —— 它不写注册表、不装服务、不在系统目录留东西。
  • 运行时生成的几个小文件（缓存、心跳、日志）都在它自己的目录里，一起删掉就行。

功能说明

按「你会看到什么」来写，不按代码结构写。

一、眼睛与状态

状态长什么样什么时候
常态睁眼，外圈是缓慢游走的辉光闲着
工作态半睁眼，外圈辉光碎成 0/1 的数字流有人报了「开始干活」，或感知到 AI 在动
有进度工作态 + 下方一条进度条任务被拆成步骤后
完成弹一张小卡片任务交付
刚开机播一遍开机动画 + 一句问候启动时（可在菜单里关掉）

二、进度条

  • 只显示「当前这一个任务」的进度，百分比按最小 1% 台阶往上爬，不会突然跳。
  • 条上写着是哪个项目（比如任务名或项目短名），一眼知道这条在跟谁。
  • 如果数字前面出现 ≈，意思是这个数有点旧了（那边有一会儿没更新）—— 「至少这么多，可能更多」，不是出错。
  • 任务完成或取消后，进度条会自己消失，不会赖在屏幕上。

三、通知卡

任务完成时弹的小卡片

  • 卡片是纯文字，自动折行，最多 3 行。
  • 读完即删：看过一次就不再弹，不会堆在屏幕上。
  • 完成卡的句式是固定的：主人，"XXX"工作空间的项目已完成N项修改，请前往查阅。

四、菜单里能改什么

分组项
显示 ▸尺寸（小 200 / 中 260 / 大 320）、字体（中 / 粗 / 特粗）
行为 ▸模式（自动 / 手动）、来源、感知、状态、置顶、开机
动作播放开机动画、归位（右下角）、退出 Fairy
「行为 ▸ 开机」里改完要重启一次才生效；菜单里悬停 5 秒会有一行说明。

五、不碰鼠标的开关

在 Fairy 目录里放一个文件就行（适合写脚本或做自动化）：

文件作用
stop.txt让它自己退出（并删掉这个文件）
poke.txt让它归位并亮出来（再双击一次启动器也是这个效果）

六、隐私与开销

  • 不联网：它没有任何对外请求，不需要账号，不需要权限。
  • 不读你的文件：它只在自己目录里读几个纯文本小文件（状态、进度、通知）。
  • 开销：平时很轻；高分屏（系统缩放 ≠ 100%）下图像缓存会按缩放变大，第一次生成也更久。

常见问题

双击了没反应？

双击 check_fairy.vbs，它会告诉你卡在哪一步（多数是没找到 Python，按「安装指南 · 四」放一个 python_path.txt 即可）。

它一直半睁着，是不是坏了？

不是。半睁 = 有任务还没结束。想让它回去：等几分钟它会自己放手；或者让 AI 把那个任务收尾。

进度条一直不动 / 一直 0%？

进度是「别人报给它」的，没人报就不会动。装过 install_agent_bridge.vbs 的话， 开一个新的 AI 任务就会正常上报。

第一次启动为什么要等那么久？

第一次要把动效预生成成缓存（常见档位约 100 秒），之后每次 0.2 秒开。想更快可以先用 python fairy_bake.py 200 260 320 把三档一次生成好。

能放到副屏吗？

目前只落在主屏，也不会压到任务栏上。移动范围限制在主屏内。

能改「主人」这个称呼吗？

可以，改程序里的文案字符串即可（界面上没有做开关）。

它会不会联网 / 上传东西？

不会。它没有任何网络请求，也不读你的文档。

想让 AI 的进度汇报更细？

那是 AI 那边的事：把任务拆得更细、每完成一小步就报一次，进度条就会更平滑。

v2.22026-09-28最新
  • 一键让 AI 配合：双击 install_agent_bridge.vbs，之后 AI 每接一个活都会自动上报（不用改任何配置、不用重启）。
  • 多任务不再打架：同时开几个任务时，进度条只跟最先开始的那个；它交付后条消失，不接棒给下一个；只要还有任务没结束就一直是工作态。
  • 取消任务立刻回常态：你点「停止」之后，它不会再挂着进度条空等。
  • 进度条上显示项目名：一眼看出这条进度在跟哪个项目。
  • 数字陈旧提示：那边一会儿没更新，百分比前面会出现 ≈ 并变淡，表示「这个数有点旧」。
  • 完成卡句式统一：主人，"XXX"工作空间的项目已完成N项修改，请前往查阅。
  • 开机问候：启动时按时间打招呼（早上好 / 中午好 / 下午好 / 晚上好 / 夜深了）。
  • 其它：耐心度调整（不轻易从工作态闪回常态）、若干稳定性修复。
